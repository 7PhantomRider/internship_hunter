# // Internship Hunter
Data Engineering project for tracking internship and job offers

## goal
end-to-end ETL pipeline that automatically collects job offers, filters relevant ones (those of interest), and notifies about new opportunities

## estimated features
- HTTP requests and HTML fetch
- web scraping offers
- Pandas data filtering and cleaning
- detecting new offers and updates
- Discord notifying
- Streamlit dashboard

## tech
Python | Requests | BeautifulSoup | Pandas | Git | Streamlit
